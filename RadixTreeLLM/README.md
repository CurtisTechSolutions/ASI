# RadixTrieLLM_RNN

In this iteration, I chose a Radix Tree specifically to focus on information compression.

This is just one variation of many to solve AGI/ASI.

Where the idea went: `RadixCyclicNN/` builds it out as a self-compressing
*cyclic* graph, and `RadixAcyclicNN/` keeps it a tree — a radix tree with no
cycles — so the two can be measured against each other.
