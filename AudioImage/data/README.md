# data

`sample.wav` is a short synthesised melody (C4 E4 G4 C5 G4 E4 C4, two seconds at
22050 Hz) — something to encode without needing a recording to hand. It is
generated rather than recorded, so it carries no licensing of its own.

Rebuild it with:

    make sample

Anything else that lands here (`*.wav`, `*.png`) is ignored by git.
