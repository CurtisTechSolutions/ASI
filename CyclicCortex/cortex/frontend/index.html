CyclicCortex

A cyclic graph over games where distance is similarity, partitioned into regions, each region owning one self-building network that reads the common denominators. Watch it learn, then sit down and play it.

Distance is similarity

Jaccard distance over mechanic sets — a proper metric, so the geometry is consistent rather than a figure of speech. The map places the games by that distance alone (classical multidimensional scaling of the matrix); the matrix beside it is the raw numbers.

Regions

A game is routed to the nearest region, or founds a new one when nothing is close enough. Each region owns one network and one vocabulary; a slot index, once given, is permanent — extension only appends, which is why growth can be an identity.

How each game was routed

Build, fork and checkpoint

Order matters: each game is routed against the regions that already exist. Admitting a game to a trained model grows the vocabulary and the network's inputs — an identity at the moment it happens, which is the invariant the whole design rests on.

Run something and watch it

Every job here is the call the command line makes, in a loop over chunks, with a measurement after each one. Three end points at 400, 1200 and 3000 episodes is a claim about a curve; this draws the curve.

Regions as players

    
Coverage is what a region bids with: the fraction of a game's mechanics its
      vocabulary can encode at all. Shapley divides the ensemble's log-likelihood among the regions —
      exact below twelve of them — and the auction sells seats at the highest losing bid, so bidding
      true value is dominant.

Cross-region transfer — real, and small

    
Regions share no weights, so an ensemble is the only channel by which
      one region's learning can reach another's game (DESIGN.md §15.1). Each game is
      answered four ways: by its own region, by the two regions that win the auction, by every
      region at once, and by the majority baseline. The question is whether any column beats the
      first — and the honest answer measured so far is one case does and the rest are flat,
      which is what it means for the graph to earn its place by placing games rather than
      by regions teaching each other.
