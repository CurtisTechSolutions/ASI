# 2NRL on CartPole

Testing the 2NRL cycle from the RadixCyclicNN research on a control task instead
of text: **train on failure, invert the network, fine-tune.**

The network is a plain feed-forward net built on the sine-wave activation from
`Research/SineWaveActivationFunction.md`, `f(x) = a*sin(b*(x-h)) + k`, with all
four parameters learnable per neuron.

## The result

The network is trained *only* to knock the pole over as fast as it can. It never
sees the balancing task. Then its sign is flipped once:

```
trained to fail   9.2  steps
       INVERT     -> 499.4 / 500     (no training, one closed-form sign flip)
    fine-tune     -> 500.0 / 500
```

Fine-tuning was not needed - the inversion had already taken it to the ceiling,
and the positive phase only had 0.6 points left to recover. For reference, the
earlier sinewave test in `Experiments/ActivationFunctionTest/README.md` reaches 28-48 on the
same task.

## The three phases

1. **negative** - reward `-1` per step, so the policy is pushed to lose as fast
   as physically possible. This is "train on garbage", except the garbage is
   generated by the network itself.
2. **invert** - `SineNet.invert()`. Every win becomes a loss and every loss
   becomes a win: the output negates exactly, so `argmax` becomes `argmin` and
   the move the failure policy most wanted is the one it now least wants.
3. **positive** - fine-tune on the real reward at a smaller learning rate, the
   activation parameters at a tenth of it, matching `TrainConfig.lr` / `act_lr`.

## Grading the loss, and venturing out by it

The negative phase has a degenerate solution: always push the same way tips the
pole in about ten steps whatever the state. A constant policy inverts into
another constant policy, and the whole exercise proves nothing. Escaping it is
what the exploration rule is for.

Every state is graded by how far it is from falling over, in normalised
state-space units:

```
margin(s) = 1 - max(|theta| / 0.2095, |x| / 2.4)      1 = upright, 0 = at the edge
```

The negative phase is aiming at margin `0`. Its loss for an episode is therefore
just the margin it actually held - hold 0.6 and you lost by 0.6 - and **that
number is how far out the next episode starts, equally in every direction**:

```
delta  = |target - achieved|
radius = delta                 direction uniform on the sphere, distance = delta
```

Margin and radius are the same normalised distance, which is what lets a graded
loss be spent directly as a distance to explore. The loop is self-regulating:
failing is easy near the edge, so a wide start scores a small loss and pulls the
next start back in; failing near the upright is slow, scores a large loss and
pushes the next start out. Across every seed it settles at **0.53** on its own.

The same grade also weights training: how well an episode *hit* the target
(`1 - loss`) scales how hard it trains, which is `two_nrl`'s `bad_weights` -
the worse a failure, the harder the network is pushed to reproduce it.

Sampling on the *surface* at that distance matters. Sampling uniformly inside
the ball puts most of the mass back near the origin, where a constant push is
already almost the fastest way to fall (9.4 steps against 8.6) - too small a gap
to learn from. Out on the surface the gap is 9.9 against 6.8.

## Results

| stage | seed 0 | seed 1 | seed 2 | mean |
|---|---|---|---|---|
| untrained | 80.3 | 9.0 | 9.9 | **33.1** |
| after negative phase (trained to fail) | 9.2 | 9.2 | 9.1 | **9.2** |
| **after inversion — no training** | 500.0 | 498.5 | 499.6 | **499.4** |
| after fine-tune | 500.0 | 500.0 | 500.0 | **500.0** |
| control: same net, same env steps, no 2NRL | 500.0 | 295.7 | 500.0 | 431.9 |

### What the negative phase learned

| seed | steps to fail | graded loss | venture radius | majority action | anti-balance |
|---|---|---|---|---|---|
| 0 | 7.9 | 0.54 | 0.54 | 52% | 96% |
| 1 | 7.7 | 0.53 | 0.53 | 55% | 95% |
| 2 | 7.8 | 0.53 | 0.53 | 52% | 92% |

### Ablations

| variant | inverted, no training | failure policy |
|---|---|---|
| **graded loss `|target - achieved|` drives the radius** | **499.4** | majority action 53%, anti-balance 94% |
| ratio delta `L_min/L` (saturates at the max radius) | 344.5 | majority action 56%, anti-balance 85% |
| graded loss, but no `bad_weights` (every failure trains equally) | 447.3 | majority action 53%, anti-balance 92% |
| no venturing out at all (standard resets) | 36.4 | majority action 87%, anti-balance 63% |

Every part of the exploration rule is load-bearing. Without venturing out the
failure policy collapses to a constant action and the inversion buys nothing
(36.4). With a saturating ratio instead of a graded loss it works but leaves a
third of the performance on the table (344.5). Dropping `bad_weights`, so every
failure trains equally hard regardless of how well it hit the target, costs
about 50 points (447.3).

## Inverting a feed-forward stack: the parity correction

In the radix graph an edge's score is a *product*, `w * f(z_p) * f(z_c)`, so
`graph.invert()` flipping every weight and every amplitude flips the score
exactly once - the two amplitude flips cancel inside the product and the parity
works out for free.

A feed-forward stack **composes** instead, and there the same literal rule
cancels itself. With `h = k = 0` the sine is odd, so per layer:

```
z'    = (-W)x + (-bias) = -z
f'(z') = (-a) * sin(b * -z) = a * sin(b * z) = f(z)        unchanged
```

Every layer cancels and the network comes back identical - flipping *everything*
is a no-op. `SineNet.invert_literal()` and `test_invert.py` demonstrate it at 2,
3 and 4 layers.

`SineNet.invert()` breaks parity exactly once instead. Writing `s` for the sign
entering a layer, `t` for the sign forced onto its pre-activation and `sigma`
for its output sign:

```
W' = t*s*W      bias' = t*bias
t = +1:   a' =  sigma*a    h' =  h    k' = sigma*k
t = -1:   a' = -sigma*a    h' = -h    k' = sigma*k
```

`t = -s` flips every weight matrix (the research's rule) and `sigma = -1` from
the break layer on negates the output once. With the break on the last layer:
every layer flips `W`, `bias` and `h`; every layer flips `a` **except the last**;
the last flips `k`. Measured error over every run: **0.0e+00**.

Two properties worth noting. The inversion is an involution - applying it twice
is the identity - and the hidden activations are bit-for-bit unchanged, so it
does not damage what the negative phase learned, it only re-reads it with the
opposite sign. And it exists at all only because the sine activation is odd; the
exactness is a property of the activation function, not of the training scheme.

## Files

| file | what it is |
|---|---|
| `sinenet.py` | the network: learnable per-neuron sine activation, backprop, Adam with a separate `act_lr`, and `invert()` |
| `twonrl_cartpole.py` | the three-phase experiment, the graded loss and the venture-out rule |
| `test_invert.py` | 14 correctness proofs: analytic gradients vs finite differences, exactness of the inversion, the parity no-op |
| `Makefile` | one target per version; `make help` lists them |
| `summarize.py` | rebuilds the tables above from the run JSON |
| `results/` | run logs and JSON for every table here |

## Running it

```bash
make install        # numpy + gymnasium, the only two dependencies
make help           # every target
make test           # the 14 correctness proofs
make quick          # one seed, ~30 s: the whole cycle end to end
make run            # the headline result (3 seeds + step-matched control)
make all            # proofs, then every version below, then rebuild the tables
```

Each version is one target, and each reproduces the row of the ablation table
above and writes its own JSON into `results/`:

| target | what changes | inverted, no training |
|---|---|---|
| `make margin` (= `make run`) | graded loss `\|target - achieved\|` sets the radius | **499.4** |
| `make speed` | ratio delta `L_min/L`, which saturates at the cap | 344.5 |
| `make no-weights` | drops `two_nrl`'s `bad_weights` | 447.3 |
| `make no-venture` | never ventures out - standard resets | 36.4 |

Override anything on the command line, as in `RadixCyclicNN/Makefile`:

```bash
make margin SEEDS="0 1 2 3 4" NEG_UPDATES=200
```

Roughly three minutes a seed on one core, pure NumPy. The ablations fine-tune
for a single update (`ABL_POS_UPDATES`) because what they measure is what the
inversion alone buys, not the final score.

## Caveats

- Three seeds, one task. CartPole is small enough that the inverse of a good
  failure policy *is* a good balancing policy; that is why the method shines
  here and it will not hold everywhere.
- The step-matched control reaches 431.9 and solves 2 of 3 seeds, so the
  interesting claim is not the final score - it is that 499.4 of it arrives from
  a closed-form sign flip, before any training on the real task.
- The learning rates keep the research's 5:1 negative-to-positive ratio and its
  `act_lr = lr/10`, but are scaled down (0.01 / 0.002) for Adam on a policy
  gradient.
