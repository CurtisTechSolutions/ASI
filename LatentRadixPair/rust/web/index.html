Predict

Continue a prefix one byte at a time from the exact fold. Each bar is what a step cost in bits.

Fold

What the model expects after a context: its code, what each level of the code stands for, and the next-byte distribution.

Judge

A verdict is worth strength ÷ outcomes per rung: the more finite the space it comes from, the more one verdict says. The prefix is context, not outcome.

Read

Read texts into the count tree. Blank lines separate texts; one file is one text.

Score

Price a text: bits per unit under the model's belief, and the reward tree's readings of its steps.

Tokenizer

Train a new context tokenizer on a corpus. This replaces the model on the server with a fresh one (the trees are primed again and, if asked, read the corpus).

Rust port with a web frontend. Design in ../DESIGN.md.
